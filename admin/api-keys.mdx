---
title: "API keys"
description: "Add the keys that unlock richer recon and OSINT sources."
---

Some tools do more with an API key. **Settings** holds per-client keys for sources such as ProjectDiscovery (Chaos), Shodan, GitHub and Canary, stored encrypted on the machine and never shared.

<Frame caption="API keys for ProjectDiscovery, GitHub, Shodan and more">
  <img src="/images/settings/api-keys.png" alt="API keys for ProjectDiscovery, GitHub, Shodan and more" />
</Frame>

Keys are optional: D0pam1ne works without them, and simply reaches more sources when they are present.

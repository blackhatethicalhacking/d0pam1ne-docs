---
title: "Evasive Mode in attacks"
description: "Pace the attack and route it through Tor to avoid blocks."
---

The same [Evasive Mode](/recon/evasive-mode) that quiets recon applies to the Attack pages. On an automated run it paces each tool against how the target responds, backs off on rate-limiting, and can route supported tools through Tor with exit-IP rotation.

<Frame caption="Evasive Mode active on an automated attack">
  <img src="/images/attacks/evasive-mode.png" alt="Evasive Mode active on an automated attack" />
</Frame>

A badge shows when Evasive Mode is on and at what intensity (quiet, balanced, aggressive), and the live run surfaces the current pacing state so you can see it throttle, cool down and resume.

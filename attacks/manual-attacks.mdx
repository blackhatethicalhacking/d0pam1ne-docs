---
title: "Manual Attacks"
description: "A targeted toolkit that uses recon's results as its targets."
---

**Manual Attacks** is the hands-on toolkit. It reads recon and, for each category, builds the in-scope target lists so every tool runs against the right hosts, services and URLs, and you decide what to run and when.

<Frame caption="The Manual Attacks toolkit, organised by category">
  <img src="/images/attacks/manual-attacks.webp" alt="The Manual Attacks toolkit, organised by category" />
</Frame>

Categories include Web scanners, TLS, Takeover, injection, API and GraphQL, Redirect/CRLF/CORS and headers, CMS, Admin panels, Network and Cloud. Each tool's command comes pre-filled with the targets recon found, so you can review, adjust and run. Findings flow back into [Issues](/data/issues).

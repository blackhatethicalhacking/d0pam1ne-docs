A **project** is one engagement. Each project carries its own client, scope, recon results, attack findings, OSINT, traffic log and reports. Open one to drill in, or start a new one when you take on new work.

<Frame caption="The Projects list: recon and attack status per engagement">
  <img src="/images/projects/projects-list.webp" alt="The Projects list: recon and attack status per engagement" />
</Frame>

Each card shows live recon and attack status, the risk breakdown and how fresh the recon is. From here you create a new project, import an existing scan, or jump into the per-project dashboard.

<Frame caption="A single project's dashboard">
  <img src="/images/projects/project-dashboard.webp" alt="A single project's dashboard" />
</Frame>

The project dashboard summarises IP addresses, open services, live URLs and screenshots, the external and internal network split, issues by risk and the current recon state, with quick actions to edit scope, run recon or export an archive.

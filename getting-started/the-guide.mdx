D0pam1ne ships with a built-in **Guide**: one scrollable page that explains the whole pipeline from first scope to final report. It is always available from the sidebar under Support, and it mirrors this documentation for when you are working offline.

<Frame caption="The in-app Guide explains the recon to report pipeline">
  <img src="/images/getting-started/guide.webp" alt="The in-app Guide explains the recon to report pipeline" />
</Frame>

The Guide walks the **pipeline stage by stage**: Scope, Recon, OSINT, Project Data, Attack, Needs Review and Report, and covers the two ways to attack (Manual and Automated). Use it as a quick refresher; use these docs for the detail and screenshots.

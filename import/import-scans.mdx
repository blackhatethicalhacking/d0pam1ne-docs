---
title: "Importing scans"
description: "Bring existing tool output into a project."
---

Already have scan output? **Import** brings it into a project. Drop the files and D0pam1ne detects the format automatically, then folds the hosts, services and findings into Project Data alongside anything recon found.

<Frame caption="Import data from tools: drop files, format detected automatically">
  <img src="/images/import/import-scans.webp" alt="Import data from tools: drop files, format detected automatically" />
</Frame>

Supported formats include Nmap and Naabu, OpenVAS, Nuclei, Burp Suite, OWASP ZAP and more. Choose whether the import is treated as external or internal, and D0pam1ne deduplicates against what is already there.

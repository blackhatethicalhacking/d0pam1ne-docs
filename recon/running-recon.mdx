Start recon and the pipeline runs stage by stage, streaming progress as it goes. You can pause or stop at any time.

<Frame caption="Recon running: pipeline stages and live counts">
  <img src="/images/recon/recon-running.png" alt="Recon running: pipeline stages and live counts" />
</Frame>

The run shows live counts for subdomains, resolved hosts, open ports, services, live web, URLs, parameters, screenshots and more, with the current tool and stage. Findings flow into [Project Data](/data/hosts-and-services) as they are confirmed, so you can start reviewing before the run finishes.

The **Tools** page is the engine's toolchain: what each tool does, its installed version against the latest release, and install or update in one click (it runs `d0pam1ne tools update` on the machine as a background job, streamed to the page).

<Frame caption="The Tools page: ready, updates available, not installed">
  <img src="/images/tools/tools-overview.webp" alt="The Tools page: ready, updates available, not installed" />
</Frame>

Tools are grouped by category: Subdomains & DNS, Ports & services, Live web, URLs, Content discovery, Parameters, JavaScript & secrets, OSINT, the Attack categories and the Evasion (Tor) tools. Filter by recon, OSINT, attack or core, check for updates, and install only what is missing.

---

Active subdomain, content and parameter discovery lean on **SecLists** wordlists. D0pam1ne installs and keeps them updated, and the Tools page shows what is present at each size.

<Frame caption="SecLists wordlists for subdomain, content and parameter discovery">
  <img src="/images/tools/tools-wordlists.webp" alt="SecLists wordlists for subdomain, content and parameter discovery" />
</Frame>

Each profile picks the wordlist size that fits (Fast uses small lists, Deep uses large ones), so you rarely choose by hand, but you can see and update them here.

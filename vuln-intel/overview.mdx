**Vuln Intel** is a vulnerability-intelligence search built on ProjectDiscovery's data. Search by product, keyword or CVE ID and read the signals that tell you what is actually being exploited.

<Frame caption="Search the vulnerability intelligence API">
  <img src="/images/vuln-intel/search.webp" alt="Search the vulnerability intelligence API" />
</Frame>

It surfaces **EPSS** (the probability a CVE is exploited), a CISA **KEV** flag (known-exploited), **CVSS** severity, public proof-of-concept availability and Nuclei template coverage, so you can tell how likely and how real a given issue is.

<Frame caption="Vuln Intel results with severity, CVSS and EPSS">
  <img src="/images/vuln-intel/results.webp" alt="Vuln Intel results with severity, CVSS and EPSS" />
</Frame>

Open any result for the full detail: description, vector, affected versions, remediation and references.
